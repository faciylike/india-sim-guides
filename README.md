## 二、 套餐与价格：2025年，多少钱能搞定？

　　价格这东西每年都在变，但2025年的行情大致如此：一份包含每天1GB高速流量（之后降速）、无限本地通话和100条短信的月套餐，价格通常在250卢比左右（约合22元人民币）。如果你是个重度用户，需要每天2GB以上流量，那月预算得准备到400-500卢比。

## 三、 生死关头：KYC实名认证怎么做？

　　这是最关键的一步，没有之一。印度政府对手机卡实名制的要求严格到近乎偏执。你必须亲自带着：**1) 护照原件；2) 含有印度签证页的护照复印件；3) 一张证件照**，去运营商柜台办理。店员会帮你填写表格，有的甚至会现场给你拍个照存档。

　　有没有遇到过没带照片的时候？有些大城市的门店支持现场拍照，但别指望所有地方都行。最好还是提前准备好。切记，绝对不要从路边小贩手里买那种所谓“已激活”的卡，百分之百是用的他人信息，后患无穷。

## 四、 让网络跑起来：APN设置与频段兼容

　　这可能是最让人沮丧的一环：卡插进去了，信号满格，但就是上不了网！十有八九是APN（接入点）没自动设置。你需要手动新建一个：
*   **Jio**: APN名称设为 `jionet`。
*   **Airtel**: APN名称设为 `airtelgprs.com`。
*   **Vi**: APN名称设为 `www`。
　　（其他字段通常留空或默认即可，设置完记得重启手机。）

　　还有一个隐藏关卡是手机频段支持。印度的4G主要用Band 3, 5, 40, 41。好在近几年出的手机基本都是全球频段，问题不大。但如果你拿着一台非常老或特定区域的合约机，最好提前查一下。
